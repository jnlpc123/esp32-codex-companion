# 1.2.1 圆点旋转验收 · 2026-10-29

## 功能与自动回归

任务圆点及前景位置作为同一逻辑布局旋转。角度变更使布局缓存失效，清理旧位置；混合长宽比切换保持背景正确。0度布局、颜色、半径、弧形与溢出空心规则保持。继续复用原51,200B RGB565画布，没有额外全帧申请。

104项Python和15组Node/C套件。实际C渲染器以独立逻辑画布逐像素旋转golden对照，覆盖3屏、4角度、7种源图尺寸、80/112/132/144前景、0/1/5/6/9999计数、无图清屏、计数改变、同revision改变角度与混合比例；画布峰值51,200B。

## 实机自动验收

本次为COM9、尾号4c6c的ESP32-C3 4MB，已单独进行全Flash只读备份、原配置/网络状态及全部50个文件的SHA-256快照；不复用另一台设备的备份。

为了观测实际输出，私有临时镜像仅在RAM设置角度，在同步SPI发送完成后记录实际footer区域、CRC和前景区域，并记录旋转时整屏背景清除；测试源临时改动已恢复，私有指令和镜像不进入公开源码或正式发行包。0/90/180/270度、80/112/144前景和1/6任务共24组，另4角度零任务，共28组、84次三屏核对全部通过。实心/溢出空心、旋转区域、前景避让及角度变化清屏正确；期间未重启。

维护者已目视确认整轮循环：圆点与前景同步旋转，无残影或遮挡。

## 正式镜像检查

正式版只写0x10000应用，不改分区表、NVS或SPIFFS布局。正式固件已在当前设备烧录并通过工具哈希校验，设备报告1.2.1；原设置和离线选项恢复，与验收前相同。全部50文件清单及内容SHA-256一致，SPIFFS剩余2,229,382B。正常联网及三屏播放帧计数增长，测试窗口无重启；实测原素材约23.69/16.62/23.69 FPS（遵循原素材时序，不作为30 FPS承诺），15次USB状态采样最大16ms。正式镜像二进制及USB协议均确认不含私有测试指令。正式源码、Windows包和源码包均需完整回归，提交及SHA-256见发行附件。

既有版本及标签保持，应用镜像不是空白芯片完整量产固件。扬声器听感、第二电脑反复物理拔插及长时间运行仍未等效完成专项验收。私有测量验证的是提交给实际LCD接口并同步发送完成的数据，实体屏幕观察与此分别记录。
