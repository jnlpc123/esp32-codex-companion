# 双按钮清理与恢复：实机验收

日期：2026-10-27。固件：1.1.0-rc.1。用户明确授权完整清理验收并恢复，目标为已核对身份的 ESP32-C3。此次没有修改固件代码或分区表。

验收前重新保存完整 Flash 备份，校验其文件清单和恢复镜像，并为 Wi-Fi、应用配置建立不含明文值的校验信息。两次清理均从 USB 本机后台点击相应按钮、核对删除范围并确认。

“清除内存”移除的逻辑文件大小为 1,270,511 字节，实际释放 1,343,101 字节，差值包含文件系统分配开销。剩余 75 文件逐一核对 SHA-256，均与验收前一致；其中包含暂停屏的完整素材序列、预览和时序文件。

“全部清除”移除剩余素材 376,685 逻辑字节，实际释放 398,839 字节。两个任务均返回 errors=0、result=0。剩下的 20 个系统及未知文件逐一核对 SHA-256，全部未变。重启后素材选择仍为空，其余显示设置与验收前一致；Wi-Fi 配置键值校验一致。

最后恢复本轮验收前的文件系统镜像，再恢复原三屏选择和应用配置。恢复后 261 个文件的清单、大小和内容 SHA-256 完全一致；Wi-Fi 与应用配置的 4 个 NVS 键值校验一致。应用分区及分区表保持不变。

本板此次没有派生缓存文件，缓存保护与删除由已有 C fixture 覆盖；旧 JPEG 派生缓存专项仍属于未完成验收。物理断网、USB 拔插/第二板/电脑重启、上传期间真实授权与问答、扬声器听感及一个工作日观察也继续保留为待验证项。此记录不等于正式版发布完成。
