# 1.1.0 正式发行验证记录 · 2026-10-27

按维护者要求，将 1.1.0-rc.2 的已实现功能正式发行。此变更统一版本标识、发行包、部署提示词和说明，不修改运行时逻辑。既有候选版标签及发行附件保留，v1.1.0 成为最新正式版本。

## 验证范围

发布前重新编译 ESP32-C3 应用，运行完整默认回归，并对 Windows ZIP 与源码 ZIP 解压后各自运行回归；具体计数、提交及 SHA-256 记录于发行附件 manifest.json 和 SHA256SUMS.txt。固件仅适用于已有兼容引导程序/分区表的应用升级，偏移 0x10000。

RC2 已完成的实机依据见 [灯效与内存验收](effects-memory-1.1.0-rc.2.md) 和 [USB 后台验收](usb-storage-1.1.0-rc.1.md)。包含四种灯效、同步/错峰、旧 JPG 首次建缓存、约 30 FPS 测试素材、USB 分块/CRC/回滚、上传并发状态以及保留当前素材的清理和内容哈希核对。正式版构建与设备更新的结果由本次发布记录另行保存，不将 RC2 结果改写为新增实测。

## 本次正式构建实机检查

只写 0x10000 应用分区，烧录工具哈希校验通过。设备报告 1.1.0，三屏配置保持、播放帧计数增长、检查期间未重启；58 个文件的清单与升级前一致，其中全部 55 个当前素材文件 SHA-256 匹配，名义可用空间保持 2133500 B。此轮未再次清理或上传测试素材。

## 已知限制

- 一个工作日持续运行、物理断 Wi-Fi / USB 反复拔插、第二电脑与换板、上传中真实授权/问答整链路尚未完成全部专项验收。
- 未安装扬声器，提示音听感未验收。
- 默认关闭灯效、合适素材以约 30 FPS 为目标；GIF 原延时和共享 SPI 负载会影响实际帧率。
- 精确授权检测面向 Windows Codex 桌面；CLI 自动审查可能误判黄灯，其他平台及云任务未等效验证。
- 运行中 Wi-Fi 超时转 AP、录音不在此版本新增范围。

上述项目继续作为后续验证工作保留，不因正式发行而宣称通过。发行包不包含本机用户媒体、账号、运行队列或 Flash/NVS 备份。
