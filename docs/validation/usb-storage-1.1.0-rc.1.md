# USB 存储候选版验收记录

日期：2026-10-27。版本：1.1.0-rc.1。ESP32-C3、4 MiB Flash、ESP-IDF 6.1、Windows / Python 3.12。

## 已验证

- 应用只写入 0x10000，不移动分区，不擦除 NVS/SPIFFS；烧录校验和启动握手成功。
- 原 SPIFFS 可用总量 2,583,041 B；当前三屏素材 376,685 B，其余 17 组已上传素材 1,270,511 B。容量偏小来自历史上传保留，未证明文件系统损坏。
- 原始 Flash 备份与测试后 SPIFFS 解析对照，原 261 个文件内容 SHA-256 全部一致。原三屏选择、颜色、亮度 26、前景 112、音量 40 与空闲设置恢复。
- 94 项 Python、8 组 Node/C 套件通过，包含实际 C 清理策略、保护共享/暂停素材、全部清除策略、系统文件保留、部分失败、Host/Origin/token/设备绑定、断代与丢 ACK 恢复。
- 17 项实机 USB 协议检查通过，包括完整 768 B 块读回、CRC、乱序、冲突重复、重复结束、提交前激活约束、临时导入回滚及原选择保持。
- 本机后台三屏预览成功；从页面分别导入 GIF（两帧）、透明 PNG、JPG，保存及原素材回切成功。三个测试目录暂保留，约 90 KiB 逻辑大小；未删除原历史素材。
- 60 KiB 上传并发 20 次临时状态请求，往返 P95 125 ms、最大 156 ms。测的是设备协议送达，不包括 Windows UI 检测时间，不能替代真实 Hook 全链路验收。
- 固定原素材、亮度和前景、三屏同步工作状态，约 10 秒 A/B：

| 屏幕 | 升级前 FPS | 候选版 FPS |
| --- | ---: | ---: |
| 1 | 23.83 | 23.79 |
| 2 | 16.64 | 16.71 |
| 3 | 25.01 | 24.97 |

全部差异低于 0.5%，符合不下降超过 10% 的回归门槛。保留素材原时序，不代表所有素材均为 30 FPS。

## 未完成与限制

- 两个按钮对原素材的真实删除及恢复仍等待用户对范围的确认；目前策略 fixture、确认取消与协议拒绝不等于实机破坏性验收通过。
- 物理断 Wi-Fi、USB 拔插、另一块板切换、电脑重启、上传期间真实授权/问答/完成仍需专项验收。USB 后台代码只复用串口，单元测试拒绝将管理操作转 Wi-Fi，但尚未完成无线电断网实测。
- 旧 JPEG 派生缓存生成的实机专项测试未建立缓存，不能记为通过；已补充缓存生成/删除时的统计修订通知。
- 没有安装扬声器，未做实际听感验收。录音、运行中 Wi-Fi 超时转 AP 不在此次范围。
- 一个工作日实际使用观察尚未完成，因此交付候选版，不发布为正式 1.1.0。
