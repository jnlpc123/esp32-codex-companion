# 1.2.0-rc.1 候选版验证 · 2026-10-27

本版增加 USB 配网、恢复中屏网络提示与离线忽略选项，按维护者要求移除背景灯效。1.1.0 正式发行保留，不覆盖已有标签或附件。

## 自动验证

103 项 Python 测试与 13 组 Node/C 套件，包含本机令牌/来源/设备绑定、异步配网成功和失败、凭据边界及清零、原子凭据记录、真实渲染与动画时序。配置构造使用实际 cJSON，逐个分配点注入失败，确认拒绝不完整记录且无泄漏。无线驱动/NVS API在原生测试中为替身，真实网络另行验收。

## 实机验证

ESP32-C3 4 MB，COM10，USB 应用升级至 1.2.0-rc.1，仅写0x10000，烧录哈希校验通过。

- 使用私有临时启动镜像进入真实AP，保留NVS凭据。原AP图、连接中图、成功图按状态绘制；离线忽略立即恢复中屏，选项重启保持。临时镜像不发布，最终设备恢复正常启动流程。
- 不可用SSID连接失败，不保存新凭据、不重启；正确凭据取得IP后保存，成功图结束关闭AP并恢复动画，boot_id保持。配网时状态请求P95约31ms、最大约32ms。
- 维护者确认无重启配网后可正常打开实际Wi-Fi管理页面；自动浏览器因已保存网站权限拒绝该地址，未绕过限制。
- 正常启动复测发现4 KiB启动栈不足：读取新凭据记录与内联方向配置的2 KiB缓冲叠加。保留方向配置独立调用帧后，启动、联网与播放通过；未增加常驻堆或任务栈大小。
- 最终正常镜像：58个文件清单一致，其中55个当前素材SHA-256逐一匹配；三屏选择、颜色、亮度等支持的配置保持。NVS读回确认旧灯效字段已清除，原Wi-Fi键不变。
- SPIFFS剩余2,133,500 B；没有删除或重传用户素材。工作屏帧计数增长，连续背景采样无灯效变化。
- USB网页已移除灯效控件，保留三屏动画选择；保存设置成功，Wi-Fi连接状态与配网入口正常。

## 限制

未完成一个工作日持续运行、第二电脑/换板及反复物理拔插的专项验收；扬声器听感尚未验证。GIF按原时序播放，不保证任意素材达到30 FPS。macOS/Linux/WSL与云端任务、纯CLI精确授权检测不在Windows桌面等效验证范围内。运行中网络长期断开自动转AP仍为后续工作，启动连接失败转AP已保留。离线忽略仅隐藏提示，不清除凭据或关闭AP。
