# 1.4.0 验证范围

ESP32-C3 / Windows，2026-10-31。

- 动态灯效：等待每 500ms 明暗交替；全部完成按红→黄→绿→黄循环两轮，随后红灯保持，再按已有空闲设置切换。新工作、等待及确认完成可打断提醒，重复心跳不重播。
- 音效：原版与 8-bit 可切换，保存后用于回复、完成和部分完成提醒；静音生效。旧配置保留原版，新设备默认 8-bit、音量 30。
- 管理页：灯效、音效独立保存，不覆盖另一模块的未保存编辑。圆形取色器下方显示状态名称；屏幕旋转可保存，支持四个直角方向。
- 渲染：三屏四方向逐像素参考图覆盖前景、任务圆点、空素材加号及配网提示。改变角度后配网提示也会重绘，画布峰值仍为 51,200B。

自动回归覆盖 21 组 Node/C 套件与 106 项 Python 测试。发行前在干净 main、Windows 工具包和源码包解压内容分别完整运行。

实机仅更新应用分区。原 55 个素材文件逐个 SHA-256、剩余空间及设置保持；两种提示音均产生预期长度的 I2S 数据，静音不输出音频。8-bit 输出与用户试听确认的版本逐字节一致，音量 30 已确认清晰；原版没有额外人工试听结论。动态完成序列约 4 秒，配置 10 秒保留时约第 14 秒进入空闲动画。三屏动画持续推进，四方向设置即时生效且重启后保持。

网页已验证桌面和 390px 手机宽度，无横向溢出。桌面取色圆为 48px，手机为 44px。三个未设置 src 的隐藏预览图用于尚未加载素材的状态，机械扫描提示已人工核对。

完整镜像由同一次构建的启动程序、分区表、应用和新生成的空 SPIFFS 组成；校验映像摘要、分区 MD5、组件偏移、空白 NVS/PHY 和 4MB 大小，不含设备备份。完整镜像的文件系统另做挂载及写入后重新挂载验证；不以实机整片擦除测试代替用户数据保留。

限制：跨独立主机切换时，若新主机的完成计数低于设备已记录的计数，可能暂不播放完成灯效，详见[动态灯效说明](../task-signal-pattern.md)。本版未修改电脑端授权判断逻辑。
