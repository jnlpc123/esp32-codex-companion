# 1.1.0-rc.2 验收记录 · 2026-10-27

本次在 Windows / ESP32-C3、4 MiB Flash、既有应用与 SPIFFS 分区上验证；只烧应用，不扩大分区。此版本仍为候选版。

## 已验证

- 95 项 Python + 9 组 Node/C 套件；包含实际 C 渲染、缩放旋转、坏缓存、CRC、内存失败、灯效时序及联动帧索引。JPEG 单元测试模拟底层解码器，真实解码另在板子验证。
- 四种背景灯效变化、共享相位、跑马灯三屏轮转，不改变任务计数和基础颜色。非法配置拒绝且原设置保持；新灯效默认关闭。
- 同一动画三屏同步帧差不超过相邻帧；错峰循环维持不同相位。四帧/33 ms 测试素材三屏约 30.11 / 30.31 / 30.31 FPS。默认保留 GIF 原延时，不保证任意素材都达 30 FPS；灯效增加共享 SPI 开销。
- 清除闲置派生缓存后，用旧 JPG 目录重新建缓存并三屏播放成功，启动代次不变。播放栈增至 6 KiB，完整测试后测得最低剩余栈 2068 B；避免旧 4 KiB 栈在 JPG 高开销路径下重启。
- JPG 首次建缓存和验证复用画布，移除第二张 RGB565 大缓冲。相同专项测试的最低剩余堆从中间版本 6976 B 提至 50624 B。R5 160×160 字面量帧测试的额外应用分配峰值为 2088 B，原先为 51202 B。常驻与峰值收益不同，不能把各项节省直接相加。
- 缩放/旋转和混合长宽比背景刷新复用画布，指示点复用画布尾部。没有额外全帧临时缓冲。关闭灯效的原素材三屏帧率保持约 23.8 / 16.6 / 25.0 FPS，符合各自原时序。
- 五项网页资源从 61590 B 压至 20538 B，浏览器解压，不占设备解压 RAM。应用 1105184 B；相对此前 RC1 的 1140656 B 减少 35472 B，既有应用分区仍有约 16% 余量。应用缩小不会自动增加 SPIFFS 分区。
- 只回收名称、大小、CRC 全部匹配的 17 项原版根目录资源，共 148630 B；配置、修改过的同名文件及未知文件保留。
- 17 项 USB 分块协议专项通过。32 KiB 上传期间 20 次状态请求均重叠，P95 47 ms、最大 62 ms，完整读回及回滚一致；此值不含 Windows UI 检测时间。
- 网页保存灯效/动画联动后刷新保持，再恢复默认关闭/独立播放。桌面与 390 px 手机宽度检查通过，无横向溢出。
- 清理后原始 Flash 读回校验：保留的全部 58 个文件 SHA-256 与备份一致；其中 55 个为当前素材。引导程序/分区表逐字节相同，Wi-Fi 及非配置 NVS 键不变，应用与已校验烧录二进制一致；重启后原三屏选择及灯效默认设置保持。
- 按用户要求最终只清理未使用素材：删除 190 个历史素材/闲置缓存文件，保留原三屏完整 55 个素材文件。剩余文件共 58 个；名义可用 2133500 B，保守导入预算 1532923 B。清理前名义剩余 687238 B，设置和三屏选择保持。

## 验证边界

此前 [USB 后台验收](usb-storage-1.1.0-rc.1.md) 中旧 JPG 缓存专项已由本次补齐。物理断 Wi-Fi、第二台电脑与换板/重启、上传中真实授权或问答、扬声器听感、一个工作日观察仍未完整验收，不作为本候选版已通过项目。USB 本机后台继续使用 127.0.0.1:17831；没有 esp.local USB 域名功能。

私人媒体、USB 日志、完整 Flash/NVS 备份仅保留本机，不随发行包发布。发布 manifest 的默认回归结果绑定干净源码提交。
