# 可选任务灯效组合（1.4）

在“灯效 → 模式”选择“动态”，保存即可启用。默认仍为“静态”，旧配置升级后不会自动开启新效果。

- 工作：下屏常亮。
- 等待回复或人工授权：中屏亮、灭各 0.5 秒；闪烁期间保留等待任务的动画播放。
- 全部任务完成：按上屏 → 中屏 → 下屏 → 中屏，每步 0.5 秒，完成两轮后上屏常亮。
- 两轮共 4 秒，随后按原“完成后进入动画”设置计时。例如红灯保留 10 秒时，循环结束后再保留 10 秒；“立即进入”也会先完成两轮。“确认完成后进入”和关闭空闲动画的行为保留。

新工作或等待立即中断完成巡灯；还有其他任务工作或等待时，局部任务完成不会触发整组巡灯。重复同步同一次完成事件不会重播。

此组合使用各屏独立角色，上/中/下仍对应完成/等待/工作，颜色使用原有自定义值。选择该组合时，三屏同步灯光布局自动切为各屏独立；切回静态后可以重新选择同步布局。三屏动画的独立/同步/错峰设置不受影响。

实际任务计数不因巡灯而改变。无素材的屏幕继续显示黑底加号，配网图片优先显示；要观察灯色和巡灯，请先为相应屏幕导入素材。

提示音在独立的“音效”模块中选择“原版 / 8-bit”，不与灯效模式绑定。当前设备的 8-bit 已通过现场听感确认，音量与喇叭有关，请按需要调整。

设备持续供电且切换到另一台电脑时，若新电脑的完成序号较小，完成巡灯去重可能暂时抑制巡灯；普通状态显示不受影响。可重启设备，或切到静态再切回动态。
