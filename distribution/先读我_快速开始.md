# 首次使用快速开始

你需要一台已预装本项目固件的三屏设备、一条 USB 数据线和 Windows 电脑。设备尚未配网或没有图片也可以开始；黑底加号表示对应屏幕还没有素材。首次使用无需重新刷机或恢复出厂。

想让 Codex 帮你实际安装，请复制仓库 README 的 [首次使用提示词](https://github.com/jnlpc123/esp32-codex-companion#first-use-prompt)。以下为手动操作步骤。

1. 安装 Windows Python 3（已验证 Python 3.12），正常安装 Codex 桌面并登录自己的账号。完整解压 Windows 工具包到当前用户可写的固定位置，例如用户目录下的 `CodexCompanion`；不要直接在压缩包中运行。
2. 用 USB 数据线连接设备，首次配置只接目标设备，并退出占用串口的其他程序。在 PowerShell 进入解压后的根目录，确认这里直接包含 `companion_host` 和 `config-templates` 文件夹。
3. 阅读并同意本项目只读检测范围后，创建桌面配置并生成 Hooks 预览：

```powershell
python --version
Copy-Item .\config-templates\desktop.json .\companion_host\config.json
python .\companion_host\install.py
```

已有 `config.json` 时先备份并合并设置，保留其他字段。下载仓库源码时，模板位置为 `distribution/config-templates/`。

4. 阅读生成的 `companion_host/review-hooks.json`，核对命令指向本机 Python 和当前安装目录，再执行：

```powershell
python .\companion_host\install.py --install
```

5. 在同一用户的 Codex CLI 中执行 `/hooks`，逐项审阅、信任并启用带 `--vibe-companion` 的八项事件，然后重新打开日常使用的 Codex 桌面。若没有 CLI，按完整说明中的官方安装方式安装；写入配置不等于已启用信任。
6. 启动并检查：

```powershell
python .\companion_host\bridge.py --resume
python .\companion_host\bridge.py --status
```

应有 `connected:true`、`transport:usb`、`approval_source:uia` 和 `ui_probe_available:true`。串口自动发现；本机 USB 后台应显示 `management_available:true`。

7. 打开 `http://127.0.0.1:17831/`。未联网时进入独立配网页：可填写自己的 2.4GHz Wi-Fi，也可选择“暂不配网，离线使用”，继续通过 USB 使用。USB 配网无需把电脑切到设备热点；需要时也可连接 `ESP32_...` 热点，访问 `http://192.168.4.1/`。
8. 在管理页对应屏幕点击“导入前景”，选择自己的 GIF / PNG / JPG，等待保存成功；没有素材可先跳过。已联网后也可通过 `esp32.local` 或设备实际 IP 打开管理页。
9. 发起正常 Codex 任务，检查后台工作、等待与完成计数；已导入素材时再观察对应绿、黄、红灯。无素材时灯色目视验收可留待导入后完成。自然出现授权时观察，网页测试按钮不能代替真实任务验收。Wi-Fi 备用测试需同局域网且设备可独立供电；不具备条件可以稍后测试。

暂停和恢复：

```powershell
python .\companion_host\bridge.py --pause
python .\companion_host\bridge.py --resume
python .\companion_host\bridge.py --status
```

“存储 → 清除内存”保留当前三屏素材，删除其余上传素材；“全部清除”同时删除当前素材。恢复出厂会清除全部素材、Wi-Fi 和自定义设置；这是维护功能，不是首次安装步骤。

完整步骤见 `使用说明与Codex配置.md`。本包不含 Python、Codex 或个人账号；纯 CLI 用户使用 CLI 模板并阅读人工授权判断限制。macOS/Linux/WSL/云任务不在此 Windows 桌面方案的已验证范围内。

卸载电脑端工具：先运行 `bridge.py --pause`，再移除仅属于本安装目录的项目 Hooks、重开 Codex 并清理专用工具目录。设备中的固件与素材保留；完整步骤和可复制的 [卸载提示词](https://github.com/jnlpc123/esp32-codex-companion#uninstall-prompt) 见仓库 README。

在“灯效”选择静态或动态；在“音效”选择原版或 8-bit，两个模块各自保存。试听前先保存音效设置；实际音量与喇叭有关，可从音量 30 开始调整。
