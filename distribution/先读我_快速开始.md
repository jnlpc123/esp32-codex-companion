# 新电脑快速开始

先把本包完整解压到固定目录，例如 `C:\CodexCompanion`，不要直接在压缩包中运行。当前设备换电脑不需要刷机。

1. 安装 Windows Python 3（推荐 3.12），正常安装并登录 Codex 桌面。
2. 数据线连接板子，退出占用串口的其他工具。旧电脑先暂停桥接，避免它还通过 Wi-Fi 控制同一块板子。
3. PowerShell 进入解压后的根目录。先阅读只读检测说明；同意在本机检测 Codex 授权控件后执行：

```powershell
Set-Location "C:\CodexCompanion"
python --version
Copy-Item .\config-templates\desktop.json .\companion_host\config.json
python .\companion_host\install.py
```

4. 阅读生成的 `companion_host/review-hooks.json`，核对命令是新电脑的 Python 和安装路径，然后执行：

```powershell
python .\companion_host\install.py --install
```

5. 在同一用户的 Codex CLI 内执行 `/hooks`，逐项审阅、信任并启用带 `--vibe-companion` 的 8 项事件。若没有 CLI，按完整说明中的官方安装步骤安装；不要复制旧电脑的内部 exe 或信任记录。然后重新打开日常使用的 Codex 桌面。
6. 启动并检查：

```powershell
python .\companion_host\bridge.py --resume
python .\companion_host\bridge.py --status
```

应有 `connected:true`、`transport:usb`，桌面模式还应有 `approval_source:uia` 和 `ui_probe_available:true`。新电脑的串口可能不是 COM10，桥接会自动发现。

7. 发起实际任务验证绿灯；自然出现人工授权时保留约 5 秒观察黄灯，处理后应恢复；完成时检查红灯。网页测试按钮不能代替 Codex 绑定验收。

管理网页使用 `http://esp32.local/` 或实际局域网 IP。首次配网连接 `ESP32_...` 热点，再打开 `http://192.168.4.1/`。Wi-Fi 备用需同局域网且板子保持供电，配置完成后日常不必打开网页。

1.2.0-rc.1 与配套桥接支持 USB 本机后台：启动桥接后打开 `http://127.0.0.1:17831/`，无需设备联网即可导入、预览及管理素材。`--status` 中 management_available:true 表示可用；端口冲突看 management_error。更新桥接后请刷新页面。

“清除内存”保留当前三屏素材，删除其余上传素材；“全部清除”同时删除当前展示素材并停止播放。两个按钮都需确认，删除不可从界面撤销；Wi-Fi 与其他显示设置保留。旧版固件需只刷应用分区升级后才能使用新后台，不要擦除整个 Flash。

纯 CLI 用户改用 `config-templates/cli.json`，授权黄灯存在自动审查误判限制；不能宣称与桌面精确检测等效。macOS/Linux/WSL/云任务不在此 Windows 包的已验证范围内。

完整步骤、三屏/GIF/空间清理、迁移和排障见 `使用说明与Codex配置.md` 或同名 `.html`。本包不含 Python、Codex、账号或私人运行数据；附带的固件仅为兼容设备应用更新文件，不是空白芯片完整烧录包。

Wi-Fi 配网与“忽略配网提示（离线使用）”位于“连接与诊断”；动画联动位于“显示与提醒”。请从本发行包运行桥接，避免旧目录的进程继续接管设备。

配网：点击后台顶部“网络设置”。未联网热点入口会自动显示独立配网页；联网后访问设备IP直接进入管理页。无需Wi-Fi时选择“暂不配网，离线使用”。
